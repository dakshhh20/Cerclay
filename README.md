# Cerclay

Cerclay is a full-stack e-commerce platform built for a modern homeware store.

The project includes a customer-facing storefront, an admin dashboard, and a Spring Boot backend connected to a MySQL database.

## Features

### Customer Storefront
- Product browsing and category-based navigation
- Product search
- Product details and image galleries
- Wishlist
- Shopping cart
- Single and Set of 2 purchasing options
- Checkout and order management
- Cash on Delivery and online payments
- Shipping and order tracking
- Returns
- Product reviews and ratings
- Google sign-in
- Password and mobile OTP authentication
- WhatsApp customer support

### Admin Dashboard
- Product management
- Category management
- Inventory management
- Order management
- Customer management
- Review moderation
- Shipping management
- Return management
- Featured product management
- Store configuration

### Backend
- Spring Boot
- Java 21
- Spring Data JPA
- MySQL
- Flyway database migrations
- Cashfree payment integration
- Shadowfax shipping integration
- Google authentication
- Session-based authentication
- REST APIs
